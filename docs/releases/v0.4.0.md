Changes

- Effort follows `/effort`. A level you change during a session is read from Claude Code's conversation, so the strip no longer shows the `effortLevel` from `~/.claude/settings.json` (for example xhigh) while you work at medium. The statusLine value still wins when it is newer
- Update notices. Hachibu checks GitHub for a new version once a day. When it finds one, it sends one notification and shows the new version at the top of the menu. Updates in the menu shows the version you are running, turns the check off, and has Check Now. The check sends only the app's name and version
- Builds with Swift 6.1 as well as newer toolchains

How to update

Download `Hachibu-macos.zip`, quit Hachibu, and replace `Hachibu.app` in your Applications folder. Settings stay. The app is not notarized yet, so allow the first launch again in System Settings > Privacy & Security. Steps with screenshots: https://github.com/BoxPistols/hachibu#first-launch-allow-it-once-in-system-settings

The first time Hachibu finds a newer version, macOS asks whether to allow its notifications.

変更点

- effortが`/effort`に追従します。セッション中に変えた値をClaude Codeの会話記録から読むため、mediumで作業していても`~/.claude/settings.json`の`effortLevel`（たとえばxhigh）が出たままになることはありません。statusLineの値の方が新しいときは、これまでどおりそちらを使います
- 更新のお知らせ。1日に1回、GitHubで新しい版を確認します。見つけたら1回だけ通知し、メニューの先頭に新しい版を出します。メニューの「アップデート」では、動いている版の確認、自動確認の停止、「今すぐ確認」ができます。確認で送るのはアプリ名と版だけです
- Swift 6.1でもビルドできるようにしました

更新のしかた

`Hachibu-macos.zip`をダウンロードし、Hachibuを終了してから、アプリケーションフォルダの`Hachibu.app`と入れ替えます。設定はそのまま残ります。まだ公証を受けていないため、「システム設定」＞「プライバシーとセキュリティ」で初回の起動をもう一度許可してください。画像付きの手順: https://github.com/BoxPistols/hachibu#インストール

新しい版を初めて見つけたときに、通知を許可するかをmacOSが尋ねます。
