Changes

- Hachibu now updates itself. When it finds a new version, it downloads and checks it in the background, then shows Update to Hachibu x.y.z and Restart at the top of the menu. Click it, or the notification, to replace `Hachibu.app` and restart. Settings stay. Before replacing, Hachibu checks the zip's SHA-256 against the release, and the app's bundle ID, version and signature
- The update check now reads the list of releases and picks only Hachibu's own `v` tags, so releases of Hachibu Lite and Hachibu for Windows are never mistaken for a new version of Hachibu

How to update

This is the last update you need to do by hand. Download `Hachibu-macos.zip`, quit Hachibu, and replace `Hachibu.app` in your Applications folder. Settings stay. The app is not notarized yet, so allow the first launch again in System Settings > Privacy & Security. Steps with screenshots: https://github.com/BoxPistols/hachibu#first-launch-allow-it-once-in-system-settings

変更点

- Hachibuが自分で更新するようになりました。新しいバージョンを見つけると、裏で取得して確かめ、メニューの先頭に「Hachibu x.y.zに更新して再起動」と出します。この項目か通知を押すと、`Hachibu.app`を置き換えて開き直します。設定はそのまま残ります。置き換える前に、zipのSHA-256をリリースの値と突き合わせ、アプリのバンドルID、バージョン、署名を確かめます
- 新しいバージョンの確認は、リリースの一覧から`v`で始まるHachibuのタグだけを選ぶようにしました。Hachibu LiteやHachibu for Windowsのリリースを、Hachibuの新しいバージョンと取り違えません

更新のしかた

手で入れ替えるのは今回が最後です。`Hachibu-macos.zip`をダウンロードし、Hachibuを終了してから、アプリケーションフォルダの`Hachibu.app`と入れ替えてください。設定はそのまま残ります。まだ公証を受けていないため、初回の起動は「システム設定」＞「プライバシーとセキュリティ」でもう一度許可してください。画像付きの手順：https://github.com/BoxPistols/hachibu#インストール
