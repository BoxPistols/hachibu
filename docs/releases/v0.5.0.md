Changes

- Runs on macOS 13 Ventura, the same minimum as Claude Code. Macs that cannot go past macOS 13, such as the 2017 MacBook, iMac and MacBook Pro, can use Hachibu now. Checked on a MacBook (Retina, 12-inch, 2017) with macOS 13.7.8
- Hachibu Lite, a lightweight edition for Intel Macs (formerly TokenBar), now lives in this repository under `lite/`. Its releases use `lite-v` tags and are separate from Hachibu's. See [Hachibu or Hachibu Lite](https://github.com/BoxPistols/hachibu#hachibu-or-hachibu-lite)

Nothing else changes for people already on 0.4.0.

How to update

Download `Hachibu-macos.zip`, quit Hachibu, and replace `Hachibu.app` in your Applications folder. Settings stay. The app is not notarized yet, so allow the first launch again in System Settings > Privacy & Security. Steps with screenshots: https://github.com/BoxPistols/hachibu#first-launch-allow-it-once-in-system-settings

変更点

- Claude Codeと同じく、macOS 13 Venturaで動くようにしました。2017年のMacBook、iMac、MacBook Proなど、macOS 13より先に上げられないMacでも使えます。MacBook（Retina, 12-inch, 2017）のmacOS 13.7.8で確かめました
- Intel Mac向けの軽量版、Hachibu Lite（旧TokenBar）をこのリポジトリの`lite/`に置きました。リリースは`lite-v`のタグで、Hachibuとは別に出します。違いは[Hachibu と Hachibu Lite](https://github.com/BoxPistols/hachibu#hachibu-と-hachibu-lite)にあります

0.4.0をお使いの方にとって、ほかに変わる点はありません。

更新のしかた

`Hachibu-macos.zip`をダウンロードし、Hachibuを終了してから、アプリケーションフォルダの`Hachibu.app`と入れ替えてください。設定はそのまま残ります。まだ公証を受けていないため、初回の起動は「システム設定」＞「プライバシーとセキュリティ」でもう一度許可してください。画像付きの手順：https://github.com/BoxPistols/hachibu#インストール
